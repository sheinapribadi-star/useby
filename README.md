# UseBy

Kitchen scene: open the fridge (top shelf = use soon, bottom = longer lasting), flip the recipe book for urgency-ranked dishes, then play cook mode with stars.

**Live:** https://sheinapribadi-star.github.io/useby/

## Flow
1. Kitchen room - scan photo or sample fridge
2. Enter fridge - shelves by urgency
3. Recipe book - dishes ranked by what expires first
4. Cook mode - Prep → Cook → Plate
